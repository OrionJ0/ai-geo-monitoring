# 正式记录持久化与报告证据

## Parent

- `../prd.md`
- `../TECH-SPEC.md`

## What to build

让正式问题运行完整保存 v4 分析结构，并在运行报告中展示其他组织、竞争关系证据、候选顺序证据和目标品牌情绪证据。项目竞品仍可服务引用来源归类，但不能再进入结构化实体分析。

新证据通过现有 JSON 持久化和报告接口做加法透传，不新增无必要数据库列。CSV 导出和回导必须无损保留 v4 结构；历史 v3 及更早结果保持原样，不伪造缺失证据。

## Acceptance criteria

- [x] 正式指标生成不再向结构化分析器传入项目竞品，引用来源归类仍保持现有行为。
- [x] v4 分析结构、关系证据、候选证据和情绪证据完整写入正式记录。
- [x] 竞争实体结果包含关系、理由、证据、实际提及次数和原文表面词。
- [x] 运行报告把 v4 标记为当前版本，把 v3 及更早版本标记为历史。
- [x] 报告正确显示“其他组织”，并展示竞争、排序和情绪证据。
- [x] 历史记录没有新证据时不显示为零值，也不伪造空证据结论。
- [x] 目标品牌未提及的记录不进入情绪统计。
- [x] v4 报告导出 CSV 后重新导入，分析版本和全部新增 JSON 字段保持一致。
- [x] 页面长证据和多实体列表不会破坏正常布局或 PDF 输出。
- [x] 后端、接口、前端和 CSV 测试先失败后通过。
