# v4 语义契约与管理员测试入口

## Parent

- `../prd.md`
- `../TECH-SPEC.md`

## What to build

将结构化分析升级为 v4：在单次 DeepSeek Pro 分析中先完整抽取品牌、公司和其他组织，再逐一判断当前问题下的竞争关系、候选顺序和目标品牌情绪。竞争关系、候选清单和情绪必须携带可在原回答定位的证据。

正式分析输入不再接收项目竞品提示，提示词不使用企业名单、情绪词典、排名正则或固定句式规则。管理员设置页继续展示真实提示词、输出契约和请求参数，并能用与正式入口相同的服务临时测试 v4。

## Acceptance criteria

- [x] 当前分析契约为 `ai_structured_v4`，结构版本为 `geo_metric_input_v4`，提示词有独立修订号。
- [x] 正式分析输入、运行时字段和管理员测试入口均不包含企业清单或竞品提示。
- [x] 实体支持品牌、公司和其他组织；每个实体都有能在原回答定位的表面词。
- [x] 每个非目标实体都有竞争或非竞争结论、理由和原文证据。
- [x] 候选清单由 AI 判断是否有序，并返回理由和原文证据；实体数组顺序不产生排名。
- [x] 目标品牌已提及时，正面、中性或负面结论包含原文证据；未提及时不成为有效情绪样本。
- [x] 证据无法定位、关系缺失、结构无效或输出截断时不会生成部分指标。
- [x] 首轮无效后的第二次尝试重新审阅完整回答并生成完整 v4 JSON。
- [x] 设置页提示词接口显示 v4 契约、真实 DeepSeek Pro 请求参数和无应用层 Token 上限策略。
- [x] 相关测试先失败后通过，并证明没有 v3 fallback 或程序语义规则。
