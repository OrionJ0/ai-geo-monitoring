# 百度统计推广层级公共 API 能力验证

- 验证日期：2026-08-05
- 验证范围：2026-08-02 至 2026-08-04 三个上海完整日
- 状态：已验证；当前生产账户与当前百度统计公共 Data API 合同

## 结论

当前百度统计公共 API 不能为本项目提供可稳定关联到百度营销的推广计划、推广单元、关键词或创意层级站内行为数据。

`source/searchword/a` 可以提供一份独立的搜索词站内行为诊断数据，并能区分“是否推广”；但响应中的 `keywordId` 是百度统计侧不透明标识，与百度营销关键词 ID 不同。不得按该 ID 或搜索词文本把百度统计行为事实拼接到百度营销广告层级。

因此正式合同保持不变：

- 广告对象、广告搜索词、展现、广告点击和消费以百度营销为准；
- 网站访问、PV、UV、来源和访问质量以百度统计为准；
- 百度统计推广产品和搜索词行为只属于候选诊断数据，不进入当前页面正式合同；
- 两边重复的广告事实只用于对账，不合计、不补差、不互相兜底。

## 只读验证方法

验证在生产服务器内使用现役数据库密文对应的百度统计凭据，只调用固定官方只读端点。过程没有刷新 Token、重新授权、写数据库、修改绑定、重启服务或输出原始关键词、搜索词、URL、站点列表、Token 与凭据。

输出仅保留 method、字段名、行数、空值数量、错误码、类型分布和集合交集数量。内容相等性使用摘要比较，不保存原始业务明细。

## 真实响应证据

| 方法 | 结果 | 已观测字段或错误 | 裁决 |
| --- | --- | --- | --- |
| `pro/product/a` | 成功，1 行 | 推广产品名称；展现、点击、消费；PV、访问、访客、新访客、跳出率、平均访问时长、平均访问页数等 | 只有“推广产品”粒度，不是计划、单元、关键词或创意层级 |
| `custom/media/a?flag=plan` | 失败 | HTTP 200，业务状态失败，`910404`，`请求地址不存在` | 当前公共 API/账户不可用 |
| `custom/media/a?flag=unit` | 失败 | 与 `plan` 相同 | 当前公共 API/账户不可用 |
| `custom/media/a?flag=word` | 失败 | 与 `plan` 相同 | 当前公共 API/账户不可用 |
| `custom/media/a?flag=idea` | 失败 | 与 `plan` 相同 | 当前公共 API/账户不可用 |
| `source/searchword/a` | 成功，16 行 | `simple_searchword_title`、`is_promotion`、PV、访问、访客、新访客、跳出率、平均访问时长、平均访问页数、转化字段 | 可作独立搜索词访问质量诊断 |

为排除请求字段过多导致 `custom/media/a` 失败，又使用官方最小指标 `visit_count,visitor_count` 重试 `flag=plan`，结果仍为 `910404`，所以不能把该方法当作已接通的层级能力。

### 搜索词筛选与身份验证

- 16 行搜索词中，`is_promotion=√` 为 8 行，`is_promotion=×` 为 8 行。
- 无筛选请求与带 `source=searchBaiduPro` 的请求字段、行数、维度摘要和指标摘要完全一致。该 `source` 参数在当前报告中没有产生可观察筛选效果，不能依赖它筛选付费搜索词。
- 16 行都带 `keywordId`；推广和非推广各有 8 个不同 ID。
- 同期百度营销完整快照包含 280 个不同关键词 ID；百度统计 8 个推广搜索词 ID 与其精确交集为 0，非推广 ID 交集也为 0。
- 百度统计返回的这些 ID 不是纯十进制百度营销关键词 ID，只能作为百度统计报告内部的不透明维度键。
- `trans_count` 和 `trans_ratio` 在全部 16 行中均为 `--`。`--` 表示缺失，不能转换为零。

## 正式接入规则

1. 不实现“百度统计计划/单元/关键词/创意访问质量”正式接口；现有证据不支持这些层级。
2. 不把 `pro/product/a` 的产品级指标下钻或分摊到广告对象。
3. 不按百度统计 `keywordId`、关键词名称或搜索词文本与百度营销事实关联。
4. 如未来展示百度统计搜索词，必须单独命名、单独返回、单独分页，并明确它包含推广与非推广访问词；只能依据已验证的 `is_promotion` 响应字段做报告内分类。
5. 百度统计搜索词原文属于高基数字段。缓存、日志、fixture、AI 证据包和公开响应必须分别经过用途、最小化、长度、分页和隐私审查。
6. 百度统计候选诊断数据失败不得阻断百度营销四报表正式快照，也不得覆盖最近一份完整广告快照。

## 重新评估门禁

只有以下条件全部满足，才能重新讨论计划、单元、关键词、创意或搜索词行为的正式接入：

- 官方文档与当前账户真实响应同时证明 method 可用；
- 维度稳定键、ID 作用域和与百度营销的关系被真实验证；
- source/device/date 等筛选实际改变响应，并有负向合同测试；
- 分页、日期上限、时区、数据延迟、配额和错误语义已经固定；
- 比率、转化和 `--` 的空值口径已确认；
- 页面有明确市场决策用途，而不是因为上游“有字段”就接入。
