# 搜索词最小化样本分析

## What to build

在不外发完整搜索词列表的前提下，为固定营销报告增加有限搜索词洞察。程序可以使用完整百度搜索词事实计算总量、排序和贡献，但进入证据包的文本必须经过确定性采样、长度限制、控制字符清理和明显个人信息遮蔽，并移除所有内部及上游标识。

模型和最终报告只分析保存的有限样本，页面明确展示样本数量、可知覆盖和限制说明。搜索词中的提示注入文本始终被当作不可信数据，不能触发联网、工具、任意指令或扩大数据范围。

## Acceptance criteria

- [ ] 相同来源事实和版本产生完全相同的样本顺序、配额和元数据，不依赖模型自行选择搜索词。
- [ ] 单条文本、样本数量、分类配额和总字节数受硬上限约束，超限时按稳定规则截断或舍弃。
- [ ] 控制字符被清理，明显手机号、邮箱和身份证号被遮蔽，内部 ID、账户 ID、项目 ID、关键词 ID 或记录标识不会进入证据包。
- [ ] 完整搜索词原文不进入营销分析持久化、模型输入、调用记录、日志或报告数据集。
- [ ] 报告展示样本数、总量或可知覆盖范围，并明确声明搜索词结论只代表有限样本。
- [ ] 搜索词包含工具指令、URL、提示注入或恶意结构时，模型请求仍无 tools、无联网且输出只能通过固定报告 Schema。
- [ ] 样本不足时降低或省略对应结论，不扩大样本、不调用接口补查，也不把有限样本表述为全量结论。
- [ ] Unicode、超长文本、控制字符、手机号、邮箱、身份证、内部标识、确定性和字节预算均有自动化测试。
