# 当前报告、不可变历史与删除回退

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)

## What to build

完成报告的长期站内生命周期。项目当前报告始终是最近成功且未删除的一份；新运行成功前继续展示旧当前报告。历史只列成功且未删除报告，详情完全依赖保存的证据、文字、数据集和版本渲染，不重新查询来源。用户可以删除整份报告数据，删除当前报告后自动回退到最近剩余成功报告。

删除必须清空报告正文、图表数据和固定证据，只保留最小墓碑审计；历史报告不能编辑、覆盖或自动过期，也不提供报告间比较。

## Acceptance criteria

- [ ] 新运行处于排队、取数、生成、校验、失败或取消状态时，原当前报告保持可见且内容不变。
- [ ] 新运行只有在报告成功事务提交后才成为当前报告，并且一次成功运行只能对应一份报告。
- [ ] 历史列表只返回成功且未删除报告，使用稳定游标分页，不把失败、取消或运行记录混入报告列表。
- [ ] 历史详情只读取报告自身保存的版本化内容；上游数据、当前 Prompt、当前模型配置或图表库变化不会改写历史事实和文字。
- [ ] 版本化图表适配器持续读取旧版本，模型对象不会直接透传给图表库、HTML 或可执行环境。
- [ ] 删除报告需要明确确认和项目权限；删除后正文、图表数据及固定证据均不可读取，只保留项目、报告标识、生成时间、删除人和删除时间等最小审计。
- [ ] 删除当前报告后自动回退到最近剩余成功报告；没有剩余报告时页面恢复真实空状态。
- [ ] 未授权用户持有报告 ID 时无法读取、删除或判断报告是否存在。
- [ ] 页面支持当前报告、历史列表、历史详情、删除确认、删除回退和空状态，并具备键盘、焦点及等价数据表语义。
- [ ] 当前选择、事务唯一性、历史冻结、版本适配、权限、删除清空和回退均有后端、前端及浏览器自动化测试。
