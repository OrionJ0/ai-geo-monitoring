# 百度统计来源纳入固定报告

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)
- [ADR 0001](../../adr/0001-marketing-funnel-data-source-of-truth.md)

## What to build

把百度统计的网站访问、UV、PV、可用质量指标、来源和趋势作为独立来源加入固定证据包、结构化报告和站内展示。每次新运行强制读取所选周期及上一周期，禁止使用缓存命中或旧缓存回退；百度统计失败不能污染百度广告事实，也不能阻止仍有可信来源时生成部分覆盖报告。

报告只在百度统计自身内部计算周期变化和图表，不把广告点击冒充访问，不与百度广告同期总量构造转化率或因果关系。

## Acceptance criteria

- [ ] 新运行通过百度统计来源模块的窄只读能力主动刷新数据，不通过内部 HTTP，也不改变现有网站流量页面的默认缓存行为。
- [ ] 百度统计响应被严格校验并映射为 DATA、ZERO、FAILED、INCOMPLETE 或其他已批准覆盖状态，失败时不得使用旧缓存 FALLBACK。
- [ ] 百度统计本期和上一周期只有在覆盖完整、口径一致时才产生变化值；其他情况显示不可比较及具体原因。
- [ ] 报告始终保留百度统计章节和覆盖状态；没有明显变化时也不删除该来源章节。
- [ ] 百度统计可用而百度广告失败时，系统仍可生成诚实的部分覆盖报告；所有当前已纳入来源均不可分析时，不调用模型且不创建报告。
- [ ] 图表只引用百度统计自身保存的数据集，不生成跨来源混合图、双轴图或没有可信关联键的转化率。
- [ ] AI 文字只描述事实、解释或待验证假设，不把访问变化写成广告投放导致的结果。
- [ ] 强制刷新、禁止回退、部分覆盖、真实零值、不可比较、单来源成功和全来源失败均有自动化测试。
