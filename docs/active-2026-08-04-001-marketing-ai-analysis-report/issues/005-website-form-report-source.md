# 官网表单来源与部分覆盖报告

## Parent

## What to build

把官网可归因成功表单提交会话的汇总、来源和逐日趋势加入固定证据包、报告与页面。系统只调用官网表单模块的聚合只读能力，按其单次范围限制安全分片，不读取联系人列表、咨询正文、电话、邮箱、IP、访客或会话标识。

本切片同时完成首版三类来源的部分覆盖语义：任何已接入来源可以独立成功或失败；至少一个来源具有完整 DATA 或 ZERO 事实时可以生成报告，全部不可分析时运行失败。53KF、线索和订单继续只显示未接入的覆盖缺口。

## Acceptance criteria

- [ ] 新运行重新读取官网表单本期及上一周期聚合事实，不通过内部 HTTP，不使用旧报告或旧缓存兜底。
- [ ] 超过官网单次范围的日期请求按确定性规则分片；只有全部分片完整、连续且合同有效才形成可比较来源结果。
- [ ] 进入证据包和模型输入的官网数据只包含聚合、逐日趋势、来源键、覆盖和取数元数据，不包含任何记录级联系人或会话信息。
- [ ] 官网 `organic_search` 等不能精确拆分的聚合来源保持 UNKNOWN，不读取联系人明细补足，也不按同期比例拆成具体搜索引擎。
- [ ] 表单咨询不被命名为全部客服咨询、53KF 对话、线索或订单；未接入来源明确显示为覆盖缺口而不是零。
- [ ] 广告、百度统计和官网表单分别保留自己的覆盖、错误和时间语义，不伪造跨来源统一 revision。
- [ ] 至少一个来源为完整 DATA/ZERO 时可以生成部分覆盖报告；所有来源均不可分析时模型调用为零、报告为零。
- [ ] 不计算没有可信来源关联和覆盖门禁的跨来源咨询率、转化率或因果结论。
- [ ] 分片聚合、隐私边界、UNKNOWN 来源、部分覆盖、全来源失败和前端覆盖展示均有自动化测试。
