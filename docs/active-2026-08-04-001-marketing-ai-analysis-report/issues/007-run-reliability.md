# 异步运行、防重复与重启收敛

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)

## What to build

把基础报告生成强化为可长期运行的异步任务：创建请求具备幂等语义，同一项目在数据库层最多存在一条未结束运行，页面离开或刷新后可以恢复观察同一任务，服务重启时所有未结束运行确定性失败且不会静默续跑。

本切片覆盖运行的排队、取数、生成、校验和终态可见性，并保证重复浏览器请求、并发提交或多进程竞争不会造成重复来源调用和两份报告。

## Acceptance criteria

- [ ] 创建运行要求幂等键；同键同请求返回原运行，同键不同请求返回稳定冲突且不产生第二条运行。
- [ ] 同一项目的不同请求在已有活跃运行时被拒绝，并返回用户有权查看的现有运行摘要。
- [ ] 数据库唯一约束是防止并发双跑的最终防线，SQLite 与 PostgreSQL 均不能通过竞态插入两条活跃运行。
- [ ] 页面防双击但不把浏览器状态作为唯一防线；离开、刷新或重新登录后可以查询并继续展示同一运行进度。
- [ ] 页面只在运行活跃时有界轮询，终态停止；隐藏页面降频，晚到响应不能覆盖更新运行的状态。
- [ ] 服务启动时把遗留的未结束运行标记为 `FAILED/PROCESS_RESTARTED`，不自动恢复、不创建报告，也不重复调用来源或模型。
- [ ] 运行详情清楚展示阶段、来源覆盖、是否已锁定基线、错误摘要和可执行能力，不把运行中或失败状态称为报告。
- [ ] 幂等重放、并发创建、数据库唯一约束、页面恢复、轮询隔离和进程重启均有自动化测试。
