# 独立营销 AI 配置与可用性检查

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)
- [ADR 0002](../../adr/0002-marketing-ai-analysis-read-only-tool-boundary.md)

## What to build

为管理员提供独立的营销分析 AI 配置和连通性检查，并让营销数据 AI 分析页面能够读取不含凭据的可用性状态。营销配置复用已有 AI 平台凭据，但平台、模型和请求参数与 GEO AI 结构化分析完全解耦；普通项目用户只能知道营销分析是否可用，不能读取或修改密钥及管理员配置详情。

本切片完成后，管理员可以保存、检查和更新营销分析配置，项目所有者可以从报告页面准确看到“可生成”或明确的配置缺失状态。它不生成报告，也不引入 Agent、工具或联网能力。

## Acceptance criteria

- [ ] 管理员可以选择具备结构化生成能力的现有 AI 平台、模型和受允许请求参数，并得到严格校验后的保存结果。
- [ ] 浏览器和普通项目用户获得的可用性响应不包含 API Key、供应商凭据、完整请求参数或其他敏感配置。
- [ ] 营销分析配置与 GEO AI 结构化分析配置使用独立存储语义；修改任一配置不会静默改变另一类后续运行。
- [ ] 平台停用、凭据缺失、模型为空或配置不合法时，营销分析页禁用生成入口并展示可操作的错误状态；管理员可进入设置页修复。
- [ ] 未登录用户、非管理员写请求和越权读取均被拒绝，且响应不泄漏敏感配置是否存在。
- [ ] 配置保存、读取、脱敏、独立性和错误状态均有后端及前端自动化测试。
- [ ] 本切片不安装或调用 Agent SDK，不接受工具定义、联网搜索参数或自由 Prompt。
