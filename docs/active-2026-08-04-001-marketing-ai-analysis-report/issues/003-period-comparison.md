# 自选周期与等长上一周期比较

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)

## What to build

把默认周期扩展为用户可选择的 1 至 90 个完整上海自然日，并在页面、API、来源读取、证据包和固定报告中一致记录所选周期及紧邻的等长上一周期。程序只在同一来源两期覆盖完整且口径一致时生成变化值；任何缺口都显示为不可比较，不裁剪日期、不补零、不外推。

本切片完成后，用户可以从日期选择到报告图表完整复核本期、上期和变化语义；最长范围所需的上游分片仍必须形成一个全成全败、可证明完整的来源结果。

## Acceptance criteria

- [ ] 页面默认最近 30 个完整上海自然日，允许选择 1 至 90 个连续自然日，结束日期不得包含上海当日。
- [ ] 发起前页面明确展示系统将读取的紧邻等长上一周期，API 不接受设备、来源选择、分析重点、模型选择或任意查询条件。
- [ ] 服务端独立校验时区、闭区间、天数和上一周期，不能信任浏览器计算结果。
- [ ] 所选周期及上一周期需要分片时，只有全部分片连续、无重复且合同有效才构成完整来源结果。
- [ ] 同一来源两期均完整且口径一致时，程序使用精确数值计算变化；缺失、失败、部分覆盖或零分母时返回明确的不可比较原因。
- [ ] 不使用主看板固定 30 日快照、旧报告证据、缓存命中或失败回退替代本次主动读取。
- [ ] 报告和图表保存本期、上期、时区、实际覆盖和比较资格；历史查看不会按当前日期重新计算。
- [ ] 日期边界、闰日/月界、最大 90 日、上一周期、分片完整性和前后端显示均有自动化测试。
