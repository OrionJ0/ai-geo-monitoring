# 冻结广告资源合同与生产基线

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)

## User stories covered

- US-2：关键词和搜索词在数据增长后仍保持有界负载。
- US-4：所有页面通过同一 revision 保持快照一致。
- US-5：迁移前有明确合同、基线和退役条件。

## What to build

在不改变当前 API 的前提下，从生产正式入口测量 Dashboard 响应体积、读取耗时、页面请求和真实消费者，冻结三个新资源的分页、排序、筛选、错误、缓存和 revision 合同，并固定广告层级与关键词的全筛选范围 summary。该证据是后续 R1 实现的门禁，不以 fixture 行数代替生产事实。
