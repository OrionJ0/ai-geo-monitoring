# visual-design-spec: 市场数据监控工作台通用视觉设计规范

## 1. 背景与设计目标

本规范用于统一广拓只读市场数据监控工作台的页面外壳、视觉层级、数据展示、组件状态、交互反馈与动效边界，使市场负责人和管理层能够快速回答：当前表现如何、变化发生在哪里、应去哪个下钻页面继续查看。

规范遵循奥卡姆剃刀和最小充分原则：常驻界面只展示完成任务所需的数据、筛选、状态、错误和口径，不用重复标题、说明卡、装饰或动效填充页面。

### 1.1 实施状态与设计参考

- 本规范与指标口径已经确认。当前工作区的 `nextjs-frontend/src/app/geo/market-overview/page.tsx` 已部分实现新版结构：投放效率、来源全链路、每日趋势和面包屑已存在，但只有百度推广广告事实与 CPC 可计算；自然来源、客服/线索/订单真实数据及其依赖指标尚未实现。相关测试和前端构建已通过，但尚未证明完整实现、提交或生产生效。
- 最终首页设计参考图：[market-overview-home-final-2026-08-03.png](active-2026-07-31-001-market-monitoring-frontend-ia/assets/market-overview-home-final-2026-08-03.png)。该图定义结构、密度和视觉方向，不构成真实数据或上线证据。

## 2. 范围与非目标

### 2.1 范围

- 工作台顶部栏、展开式侧边栏、面包屑和内容区。
- 市场总览、数据看板、列表页、详情页、设置页的通用视觉规则。
- 首页投放效率、来源全链路、微型漏斗和每日趋势的专用规格。
- 卡片、表格、图表、筛选器、按钮、标签、Tooltip、弹层和数据状态。
- 桌面端优先的响应式规则、键盘焦点、颜色对比和低动效降级。

### 2.2 非目标

- 不定义后端接口、计算服务、缓存、图表库配置或组件代码。
- 不实现后端指标计算、来源关联、数据接入或权限模型；本规范只固定前端必须表达的指标语义和状态。
- 不设计拖拽看板、自定义组件编排、个人主题或皮肤切换。
- 不引入新的字体、图标体系、品牌渐变或第三方 UI 组件库。
- 不用视觉稿暗示当前尚未具备的数据能力。

### 2.3 延后事项

- 窄屏端的完整高保真稿和移动端图表交互细节。
- 全局设计 Token 在 Ant Design 主题层的技术落地方式。
- 深色主题。

## 3. Design Read

- 页面 / 功能类型：桌面端优先的企业级只读 BI 与市场数据监控工作台。
- 目标用户或场景：市场负责人每日巡视、管理层周期复盘、运营人员按来源下钻。
- 视觉语言：极简、克制、清晰、可信；浅灰底、白色数据表面、蓝灰主色，无边框堆砌和营销化装饰。
- 交互与动效强度：低；只反馈状态变化、筛选、下钻和数据更新。
- 信息密度：中高密度，强调横向比较和快速扫描，不通过放大或过度留白制造“高级感”。
- 签名元素：展开式工作台导航、按来源横向排列的全链路表格、每行阶梯式微型漏斗、双周期投放效率卡和单指标趋势对比。

## 5. 设计原则

### 5.1 最小充分

- 一个信息只出现一次；页面、模块、指标和状态不重复命名。
- 说明优先进入标签、列名、Tooltip、空状态或错误状态，不常驻成段展示。
- 首页只承担发现和判断，账户、计划、关键词、搜索词等明细进入下钻页。
- 每个可见控件必须能解释自己的作用；没有明确行为的装饰控件不得出现。

### 5.2 数据可信

- 数字必须同时具备指标名、时间范围、单位和可访问口径。
- 百分比必须明确分母；不得只显示孤立百分比。
- 缺失值、真实零值、无权限、加载失败和未接入是不同状态，不得统一显示为 `0`。
- 数据异常用文字或图标辅助颜色，不只靠红绿表达。

### 5.3 一致但不过度容器化

- 先用间距、对齐、字号和分隔线组织信息，再使用背景、边框和阴影。
- 独立业务对象可以使用卡片；一个模块内部的普通行或指标不自动套卡片。
- 同一页面最多允许两层可见表面；投放效率是已确认的例外结构：四张独立卡直接位于页面底色，不再有外层卡。

### 5.4 组件优先与样式覆盖顺序

- 优先直接使用项目已有共享组件；没有共享组件时，优先使用 Ant Design 提供的标准组件、尺寸、状态和交互样式。
- 组件默认样式与本规范一致时不做额外覆盖，不为“看起来更定制”而重写边框、圆角、悬浮、焦点、禁用或加载状态。
- 需要全局统一调整时，优先级依次为：Ant Design Theme Token → 共享组件及明确命名的 variant → 页面 CSS Module。
- 页面 CSS Module 主要负责页面独有的栅格、间距、排列、响应式和确有业务含义的差异，不负责重新发明通用组件视觉。
- 同一语义组件在两个及以上页面使用时，应复用同一共享组件或同一 variant；若必须不同，需在规格中说明业务原因和状态差异。
- 全局 CSS 只承载设计 Token、基础重置和应用外壳；`!important` 和 JSX 内联样式不得作为常规覆盖方案，运行时动态几何除外。

## 6. 页面外壳与布局系统

### 6.1 全局外壳

| 元素 | 桌面规格 | 视觉规则 |
|---|---:|---|
| 顶部栏 | 高 64px，固定顶部 | 渐变 `#162B6F → #1F4DD2 → #5B8CFF`；白色文字；只保留必要操作。 |
| 顶部栏标题 | 20px / 28px，700 | 沿用当前“广拓数据工作台”；不在页面内容再次重复。 |
| 侧边栏 | 宽 224px，默认展开 | 白底；可独立纵向滚动；桌面不与内容一起滚动。 |
| 内容区 | 左右和顶部 24px | 背景 `#F6F8FB`；唯一主滚动区；禁止页面级横向滚动。 |
| 面包屑行 | 最小高 32px | 左侧面包屑，右侧放全局日期等页面级筛选；与下面首个模块间距 16px。 |

### 6.2 栅格与宽度

- 桌面以 12 栏概念栅格组织，栏间距 16px；不要求在代码中暴露栅格线。
- 1440px 视口下，224px 侧边栏和 48px 内容边距后，主内容自然使用剩余宽度。
- 组件高度由内容决定，不为填满截图或首屏而拉伸。
- 四张 KPI 卡在宽屏各占 3 栏；全链路和趋势各占 12 栏。
- 主要模块纵向间距 16px；跨页面语义分区可使用 24px。
- 数据表可在自身容器内横向滚动，但不得使整个页面横向滚动。

### 6.3 页面标题规则

- 直接对应侧边栏入口的一级页面：只显示面包屑，不显示重复 H1 和功能介绍。
- 详情页、报告页或对象页：允许显示对象名或报告名作为 H1，因为侧边栏无法表达当前对象。
- 模块标题用于区分页面内部内容，如“投放效率”“来源全链路”“每日趋势”，不属于重复页名。
- 禁止使用营销式 Hero、大号标语、眉题、编号章节或说明卡填充数据页首屏。

### 6.4 响应式断点

| 视口 | 布局规则 |
|---|---|
| `≥1280px` | 侧边栏展开；四张效率卡单行；全链路表格完整展示；趋势图完整展示。 |
| `992–1279px` | 侧边栏可保持展开；效率卡可两列；全链路表格允许容器内横向滚动。 |
| `768–991px` | 侧边栏根据现有断点折叠；效率卡两列；内容边距 16px；表格容器滚动。 |
| `<768px` | 侧边栏使用覆盖式抽屉，不挤压内容；效率卡单列或在 `≥480px` 时两列；趋势摘要换行；图表保持最小可读宽度。 |
| `320px / 400%` | 核心操作、标签和数值不得裁切；允许模块内滚动，不允许页面双向滚动。 |

## 7. 视觉系统

### 7.1 字体

不更换项目现有字体，不下载或引入新字体。

| 用途 | 字体规则 |
|---|---|
| 全局 UI | `var(--font-geist-sans)`，即现有 Inter、系统无衬线字体回退链。 |
| 中文 | 由系统字体回退链选择当前操作系统可用中文无衬线字体。 |
| ID、URL、代码、技术证据 | 仅在确有技术语义时使用 `var(--font-geist-mono)`。 |
| 数据数字 | 默认仍使用现有 sans 字体，并启用等宽数字特性；不为了“数据感”大面积换成等宽字体。 |

### 7.2 字号与行高

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---:|---:|---|
| 顶部栏品牌 | 20 / 28px | 700 | 工作台名称 |
| 详情页 H1 | 24 / 32px | 600 | 仅对象或报告详情页 |
| 模块标题 | 20 / 28px | 600 | 投放效率、来源全链路、每日趋势 |
| 卡片标题 | 16 / 24px | 600 | KPI、子模块、弹层标题 |
| 正文 | 14 / 22px | 400 | 默认正文、控件文字 |
| 强调正文 | 14 / 22px | 600 | 关键标签、选中项 |
| 辅助文字 | 12 / 18px | 400–500 | 单位、口径、次要数据 |
| 面包屑 | 13 / 20px | 400–500 | 层级路径 |
| KPI 主值 | 28 / 36px | 600 | ROAS、CPL、CPA、CPC 本期值 |
| 表格主值 | 16 / 24px | 500–600 | 各阶段计数或金额 |

规则：

- 数字使用 `tabular-nums`，相同列的小数位和单位一致。
- 正文不得小于 12px；关键业务数字不得小于 16px。
- 不使用超大标题或超过 32px 的数据字号占据数据页面首屏。
- 中文和英文混排时保留自然字距，不额外增加全局 letter-spacing。

| 错误 / 恶化 | `#DC2626` | `#FEF2F2` | 来源错误、危险操作、指标向不利方向变化 |
| 信息 | `#0F4FB8` | `#E6F4FF` | 选中、信息提示、主链接 |
| 中性 | `#64748B` | `#F8FAFC` | 无数据、禁用、尚无结论 |

指标颜色必须按“业务方向”而非数值正负决定：ROAS 上升为绿色；CPL、CPA、CPC 上升通常为红色，下降为绿色。没有目标或方向共识时使用主文字色，不擅自标红或标绿。

### 7.5 图表色板

| 序列 | 主色 | 用途 |
|---|---|---|
| 百度推广 / 当前主序列 | `#2F6BFF` | 付费来源、当前周期 |
| 百度自然搜索 | `#24877F` | 百度自然来源 |
| 必应自然搜索 | `#7C3AED` | 必应自然来源 |
| 上一周期 | `#94A3B8` | 灰蓝虚线，不与当前主序列争夺注意力 |
| 网格线 | `#E8EDF4` | 仅保留必要横向网格 |

- 同一来源在表格标识、漏斗、图例和趋势中保持同色。
- 当前周期使用 2px 实线；上一周期使用 2px 虚线，建议节奏为 6px / 4px。
- 同一图中常驻序列不超过 4 条；优先一次查看一个指标。
- 禁止彩虹色板、3D 图、面积渐变堆叠和无法解释的双轴图。

### 7.6 圆角、边框与阴影

| 元素 | 圆角 | 边框 / 阴影 |
|---|---:|---|
| 主模块卡片 | 12px | 1px `border`；默认无阴影 |
| KPI 卡、紧凑面板 | 10px | 1px `border`；默认无阴影 |
| 输入、下拉、按钮 | 8px | 使用 Ant Design 可见边框和焦点态 |
| 菜单选中项 | 8px | 无阴影，浅蓝背景 |
| 二级菜单选中项 | 6px | 无阴影，浅蓝背景 |
| 标签 / 状态 | 4–6px | 轻边框或浅语义底色 |
| Tooltip、Dropdown、Popover | 8px | 允许使用低强度悬浮阴影 |
| Modal / Drawer | 12px | 允许使用遮罩和中等悬浮阴影 |

- 常驻卡片不使用毛玻璃、强阴影、发光边框或高光渐变。
- 页面只允许顶部品牌栏使用现有阴影：`0 6px 18px rgba(31, 77, 210, 0.30)`。
- 不用圆角区分所有层级；优先依靠间距和分隔线。

### 7.7 间距体系

| Token | 数值 | 用途 |
|---|---:|---|
| `space-1` | 4px | 图标内部、极小分隔 |
| `space-2` | 8px | 图标与文字、紧凑控件 |
| `space-3` | 12px | 卡片内部相关元素、紧凑卡片间距 |
| `space-4` | 16px | 标准卡片间距、区块内部 |
| `space-6` | 24px | 页面边距、主要分区 |
| `space-8` | 32px | 少量跨语义大分区 |

禁止出现无规则的 14px、18px、22px、30px 间距，除非由组件固有行高产生。

## 8. 导航与页面定位组件

### C1. 顶部栏

- 角色：品牌和全局会话操作，不承担页面标题职责。
- 尺寸：64px 高；左右内边距 24px，窄屏 10–12px。
- 左侧：折叠按钮与“广拓数据工作台”，间距 12px。
- 右侧：只保留已有且必要的全局操作；默认按钮高 32px。
- 禁止：在顶部栏放页面级筛选、KPI、广告语或过多导航标签。

### C2. 侧边栏

- 角色：表达产品信息架构和当前位置。
- 桌面：224px，默认展开，白底，独立滚动。
- 一级直接入口：40px 高，14px、600；左右内边距 20px；圆角 8px。
- 分组标题：14px、600、`text-secondary`，不做可折叠手风琴。
- 二级入口：36px 高，13px、500；圆角 6px。
- 图标：统一线性图标，约 16px；图标与文字间距 8px；禁止 emoji、填充风格混用和超大图标。
- 选中态：`brand-selected-bg` 背景、`brand-link` 文字和图标；不能只靠颜色，需保留当前项语义。
- Hover：浅灰或浅蓝背景，不位移、不缩放。

### C3. 面包屑

- 位置：内容区首行左侧；全局日期等页面级筛选位于同一行右侧。
- 一级页面：`首页 / 当前页`。
- 分组内页面：`首页 / 分组 / 当前页`。
- 对象详情：`首页 / 分组 / 页面 / 对象名`，长对象名在视觉上截断但保留可访问全名。
- 详情页面：`首页 / 模块 / 对象名`；对象名过长时截断并提供 Tooltip。
- 字号：13px；历史层级 `text-tertiary`，当前层级 `text-secondary`。
- 页面无需同时显示“当前页”大标题。

## 9. 首页专用组件规格

### C4. 投放效率区

- 角色：快速判断付费来源是否值得继续投入，以及单位获客成本是否恶化。
- 表面：无外层白色卡片；标题、付费来源下拉和四张 KPI 卡直接位于 `page-bg`。
- 标题行：左侧“投放效率”和 info；紧邻一个付费来源下拉，默认“百度推广”。日期使用面包屑行的全局日期。
- 布局：宽屏四列，卡间距 16px；卡片等高但不人为拉高。
- 卡内结构：指标名与 info → 本期 / 上期双列 → 较上一周期变化。
- 默认指标：

| 指标 | 定义 | 有利方向 | 默认显示 |
|---|---|---|---|
| ROAS | 成交订单金额 ÷ 广告投入 | 越高越好 | 倍数，2 位小数 |
| CPL | 广告投入 ÷ 线索入池数 | 越低越好 | 货币 / 条 |
| CPA | 广告投入 ÷ 成交订单数 | 越低越好 | 货币 / 单 |
| CPC | 广告投入 ÷ 访问（点击）数 | 越低越好 | 货币 / 次 |

- 比较周期：与当前日期范围等长的紧邻上一周期；Tooltip 明确两个周期的起止日期。
- 禁止：小折线、每日波动、表格联动、卡片内部下拉、毛利指标、嵌套外层卡。

### C5. 来源全链路卡

- 角色：横向比较不同来源从曝光到成交订单的规模和阶段损耗。
- 表面：完整白色主模块卡，12px 圆角、1px 边框；标题和表格都在卡内。
- 固定列顺序：`来源｜广告投入｜展现｜访问（点击）｜客服咨询｜线索入池｜成交订单｜全链路`。
- 付费来源显示广告投入；自然来源显示 `—`，不得显示 `0`。
- “点击”和“官网访问”在当前设计中合并为“访问（点击）”，不得重复成两列。
- 主值下方可显示阶段转化率和成交金额等辅助值，字号 12px。
- 表头可点击列使用指针光标、可见 Hover 和键盘焦点；当前趋势指标表头使用浅蓝底和蓝字。
- 表格行点击不改变趋势来源；来源只能由趋势区来源下拉选择。

转化率口径：

| 名称 | 公式 |
|---|---|
| 点击率 | 访问（点击）÷ 展现 |
| 咨询率 | 客服咨询 ÷ 访问（点击） |
| 入池率 | 线索入池 ÷ 客服咨询 |
| 成交率 | 成交订单数 ÷ 线索入池 |
| 整体转化率 | 成交订单数 ÷ 展现 |

公式不常驻成段展示；列名或“全链路”标题旁使用 info Tooltip。成交率和整体转化率均以成交订单数作为分子。

### C6. 阶梯式微型漏斗

- 位置：每个来源行的“全链路”单元格；不在页面下方重复大型漏斗。
- 几何：5 条水平条自上而下逐级变窄，左侧共用一条 1px 垂直基线，末端形成细尾。
- 建议尺寸：图形区约 56×56px；横条高 6px、间隔 4px；宽度可按 52 / 36 / 24 / 12 / 4px 形成固定识别形，不用真实比例压缩到不可见。
- 颜色：使用该来源主色及同色透明度层级，不混入新颜色。
- 文案：右侧显示“整体转化率”和数值；数值使用来源主色。
- 可访问性：图形为辅助表达；单元格必须有完整文本值和可读口径。
- 禁止：水平进度条、3D 漏斗、倒三角、多个分散条形或用图形面积精确表达跨数量级比例。

### C7. 每日趋势卡

- 角色：查看选定来源、选定指标在当前范围内的每日变化，并与上一周期比较。
- 表面：完整白色主模块卡，标题、筛选、摘要、图表和图例全部在卡内。
- 左上控件顺序：`来源`下拉 → `指标`下拉；不再平铺指标按钮。
- 表头联动：点击全链路表格可选指标表头时，仅更新指标下拉和趋势图。
- 来源选择：只通过趋势区来源下拉变更，不由表格行隐式改变。
- 摘要：区间总量、日均、较上一周期、峰值和峰值日期；信息在同一行，空间不足时自然换行。
- 图表：当前周期主色实线，上一周期灰蓝虚线；默认只比较一个指标的两个周期。
- Tooltip：日期、当前周期值、上一周期对齐值、单位；键盘或触摸可获取等价信息。
- 禁止：与投放效率联动、重复指标按钮、多个量纲混绘、面积装饰、默认数据点全量常驻放大。

## 10. 通用组件规格

### C8. 卡片与模块容器

- 主模块卡：白底、12px 圆角、1px `border`，内边距 16–20px，无常驻阴影。
- KPI 卡：白底、10px 圆角、1px `border`，内边距 16px。
- 卡片标题与内容之间使用 12–16px 间距；除标题分割线外不添加多余横线。
- 禁止在主卡内再次套同等视觉重量的白卡；必要子分区使用间距或浅分隔线。

### C9. 表格

- 表头高约 44px，13px / 20px、500–600；背景白色或极浅灰。
- 默认数据行高 52–64px；全链路多行辅助数据允许 72px，但不得为对齐而制造大面积空白。
- 文本列左对齐，数字和金额列右对齐；阶段链路表为保持纵向扫描可使用居中数字，但同一表内必须一致。
- 表格行分隔使用 1px `divider`；Hover 使用 `#F5F7FA`。
- 长 ID、URL 和名称截断并提供 Tooltip；禁止挤压相邻关键数值。
- 多维明细表应支持固定关键列、横向滚动、排序、筛选和导出，但首页表格保持轻量。
- 空表、加载表和错误表保持列结构稳定，避免页面跳动。

### C10. 筛选器与日期选择

- 默认控件高 32px；重要或独立表单可使用 40px。
- 控件圆角 8px；字号 14px；标签与控件间距 8px。
- 全局日期放在面包屑行右侧；页面局部筛选放在所属模块标题行。
- 筛选条件超过 3 个时使用可换行工具栏或“更多筛选”，不压缩为难以阅读的小控件。
- 已选条件必须可读；清除或重置只在确实存在多个局部条件时出现。

### C11. 按钮

- 一个表面内最多一个主按钮；主按钮使用品牌蓝。
- 次要操作使用默认或文本按钮；危险操作使用红色并要求清晰文案。
- 图标按钮必须有可访问名称；仅在含义普遍明确且有 Tooltip 时省略可见文字。
- Hover 不位移、不缩放；Disabled 仍保留可辨识边界和禁用原因。

### C12. Tooltip、Popover 与口径说明

- info 图标建议 14–16px，与标题间距 6px。
- Tooltip 只包含短定义、公式、分母、单位、时间口径或异常原因；推荐不超过 4 行。
- 复杂口径使用 Popover 或帮助抽屉，不把长说明塞进 Tooltip。
- Tooltip 可通过 hover、键盘焦点和触摸触发，不能只支持鼠标。

### C13. 标签与状态

- 标签高约 22–24px，字号 12px，圆角 4–6px。
- 来源类型标签如“广告”“自然”使用浅色背景和深色文字，不抢占主数字注意力。
- 正常状态不常驻显示“已接入”“最新”“实时”。
- 陈旧、错误、权限阻断等会改变解释的状态必须在受影响模块附近显示，并带恢复或下钻方向。

### C14. 表单与设置页

- 表单内容宽度优先 560–720px，不让输入框无意义地铺满大屏。
- 标签位于控件上方；必填、帮助和错误信息位置一致。
- 同一设置主题使用一个白色主表面和分隔线，不为每个字段单独建卡。
- 保存操作固定在内容结束处或可预期的操作栏，不同时出现多个等价保存按钮。
- 高风险设置需二次确认，确认对话框明确影响范围。

### C15. 列表页与详情页

- 列表页顺序：面包屑 / 页面级筛选 → 轻量工具栏 → 单一表格主表面。
- 详情页允许显示对象名 H1；摘要属性使用描述列表，不默认转换成大量 KPI 卡。
- 详情中的趋势、分布、排行和明细按决策顺序排列；同一数字不在摘要和图表上方重复放大。

## 11. 数据状态与内容规则

### 11.1 正常状态

- 不显示更新时间、“数据最新”“实时同步”或绿色成功条。
- 用户默认看到的就是当前可用事实；只有新鲜度异常时打断。

### 11.2 加载状态

- 首次加载使用与最终结构同形的 Skeleton；保留标题、筛选器和卡片尺寸。
- 局部刷新只更新受影响模块，不将整个页面替换为居中 Spinner。
- 已有旧数据时保留旧数据并在局部显示刷新进度，不清空页面。

### 11.3 空状态

- 区分“真实零值”和“无数据”。真实零值显示 `0`；没有记录显示最短说明。
- 空状态不使用大型插画；可使用 Ant Design 简洁空状态图标。
- 只有用户能在本系统完成恢复时才显示操作按钮；否则给出明确下钻或管理员处理方向。

### 11.4 错误、陈旧与权限

- 来源错误：保留最后可用快照，模块顶部显示红色或橙色短提示和重试/下钻。
- 数据陈旧：显示最后成功时间和影响范围；这是唯一默认展示时间戳的场景之一。
- 权限不足：使用阻断态并说明需要的角色，不显示伪空数据。
- 部分失败：健康来源继续展示；错误不能抹掉其他来源数据。

### 11.5 数字与文案

- 金额必须带币种符号或币种标签；同一页面币种一致时不在每个单元格重复写币种名称。
- 大数字使用千位分隔；精度由业务口径决定，不用无意义小数。
- 比率使用 `%`，倍数使用 `x`，成本使用“货币 / 对象”。
- 缺失值使用 `—`；禁止用 `N/A` 混入中文业务页面。
- 日期范围统一为 `YYYY-MM-DD 至 YYYY-MM-DD`；图表横轴可简写为 `MM-DD`。
- 不使用“高级”“智能”“实时”“全自动”等无法由事实支持的宣传词。

## 12. 交互规格

### I1. 表头选择趋势指标

- 触发：点击或键盘激活可选择的全链路表头。
- 前置状态：趋势卡已有一个来源和指标。
- 过程：仅更新趋势指标，不改变趋势来源，不改变投放效率。
- 结束状态：对应表头显示选中态，趋势区指标下拉同步显示新值，图表更新。
- 反馈：选中表头浅蓝底、蓝字；趋势图执行克制过渡。
- 边界：不可比较或没有时间序列的列不表现为可点击。

### I2. 趋势来源与指标选择

- 触发：趋势卡左上两个下拉。
- 过程：任一变化只请求或切换趋势卡自身数据。
- 结束：摘要、图表、Tooltip 和等价数据同步更新。
- 边界：无数据时保留已选条件，显示对应空状态，不自动跳到其他来源。

### I3. 投放效率来源选择

- 触发：投放效率标题旁的付费来源下拉。
- 过程：只更新四张投放效率卡；仍使用全局日期范围。
- 边界：自然流量来源不得出现在需要广告投入的效率选择器中。

### I4. 下钻

- 触发：表格来源名称、指标卡明确链接、异常项或列表行操作。
- 结束：进入对应来源、账户、计划或明细页，并保留可复现的日期和筛选上下文。
- 禁止：整张非交互数据卡出现误导性 Hover；无下钻行为的卡片不使用指针光标。

## 13. 动效规格

动效的目标是说明状态变化，不是制造品牌戏剧性。

### M1. Hover 与焦点反馈

- 触发：鼠标 Hover、键盘 Focus。
- 变化属性：背景色、边框色、文字色；禁止位移和缩放。
- 时长：120ms。
- 缓动：`ease-out` 或等价的克制减速曲线。
- 结束状态：离开后恢复；焦点始终保留 3px 可见轮廓和 2px offset。
- reduced motion：可直接切换，无需过渡。

### M2. 下拉、Tooltip 与 Popover

- 下拉 / Popover：160ms，透明度 0→1，Y 方向最多 4px。
- Tooltip：100ms 淡入，80ms 淡出；不做缩放。
- Drawer：200ms，单向平移；遮罩透明度同步变化。
- Modal：160ms 淡入；不使用弹簧或过冲。
- reduced motion：瞬时显示最终位置。

### M3. 侧边栏折叠

- 触发：顶部折叠按钮或移动端遮罩关闭。
- 变化属性：侧栏宽度 / 位移、遮罩透明度。
- 时长：180–200ms。
- 缓动：`ease-out`。
- 桌面结束态：内容区平滑占用剩余宽度；移动端结束态：覆盖层关闭，不改变内容宽度。
- reduced motion：瞬时切换。

### M4. KPI 与表格数据更新

- 触发：日期或来源变化后数据成功返回。
- 变化：旧值透明度降低，新值淡入；不使用数字滚动或逐位计数。
- 时长：160–180ms。
- 布局：固定最小高度，更新过程中不得跳动。
- 错误：不播放成功过渡，直接进入错误或保留旧值状态。

### M5. 趋势图切换

- 触发：来源或指标变化、表头联动。
- 变化：图线和摘要 180–240ms 交叉淡化；坐标轴仅在量级变化时过渡。
- 数据点：默认不做逐点入场；Hover 点可在 100ms 内由 0 扩大至 4–6px。
- 禁止：绘线动画超过 300ms、波浪、弹跳、粒子和区域发光。
- reduced motion：直接显示新图。

### M6. Skeleton

- 触发：首次加载且没有可保留数据。
- 节奏：如保留 shimmer，周期 1200–1600ms，低对比度。
- reduced motion：使用静态骨架，不播放 shimmer。
- 性能：动画只使用 transform / opacity / background-position 等低成本属性；避免触发布局重排。

## 14. 可访问性与降级

- 所有菜单、表头选择、下拉、Tooltip、按钮、链接和表格操作均可通过键盘完成。
- 焦点样式沿用当前 3px 蓝色半透明 outline，不得被 `outline: none` 移除。
- 正文与背景对比度至少 4.5:1；大字至少 3:1；图形关键边界至少 3:1。
- 红绿变化必须同时使用 `+/-`、箭头、文字或“改善 / 恶化”语义。
- 图表提供可访问摘要或等价数据表；微型漏斗不能成为唯一数值来源。
- Tooltip 和 Popover 支持键盘焦点与触摸，不只依赖 hover。
- `prefers-reduced-motion` 下关闭非必要过渡、Skeleton shimmer 和图表绘制动画。
- 400% 缩放和 320px CSS 宽度下，关键内容不裁切；表格在自身区域滚动。
- 移动端侧栏作为覆盖层出现，关闭后焦点返回触发按钮。

## 15. 禁止风格

- 大面积毛玻璃、霓虹、强渐变卡片、强阴影、悬浮浮岛和发光数字。
- 卡片套卡片、每个指标一层底板、每个列表行一张卡。
- 为了让截图“一页看全”而拉伸侧栏、卡片、表格行或图表。
- 巨大空白、超大标题、杂志式排版、Bento 拼贴和营销落地页 Hero。
- 3D 图表、饼图堆叠、仪表盘速度表、装饰性漏斗和无业务含义的颜色。
- 默认展示“已接入”“实时”“更新时间”等安心文案。
- 使用 emoji 充当导航或业务图标。
- 自动轮播、滚动劫持、数字翻牌、卡片浮起和超过 300ms 的常规反馈。

## 16. 页面模板

### 16.1 市场总览

1. 顶部栏和展开侧边栏。
2. 面包屑 + 全局日期。
3. 无外层底板的投放效率标题、来源选择和四张 KPI 卡。
4. 有完整白色容器的来源全链路表格和每行微型漏斗。
5. 有完整白色容器的每日趋势。
6. 其他接入状态、复杂异常和说明进入数据接入或下钻页面，不在首页堆叠。

### 16.2 数据列表页

1. 面包屑 + 日期或页面级操作。
2. 局部筛选工具栏。
3. 单一白色表格主表面。
4. 分页、导出和批量操作位于可预期位置。

### 16.3 详情 / 分析页

1. 面包屑。
2. 对象名和必要元信息；只有详情页允许 H1。
3. 核心摘要。
4. 趋势 / 分布 / 明细，按“判断 → 解释 → 证据”排序。

### 16.4 设置 / 管理页

1. 面包屑。
2. 单一主表面承载一个设置主题。
3. 标签在上、控件在下、帮助和错误紧邻控件。
4. 保存和高风险操作明确分区。

## 17. 验收矩阵

### 17.1 全局视觉

- AC-001：1440px 视口中顶部栏为 64px、侧边栏为 224px、内容区为 24px 内边距，页面无横向滚动。
- AC-002：正式一级页面不重复显示侧边栏当前页的大标题或介绍段，面包屑可见。
- AC-003：全站沿用现有 `--font-geist-sans` / `--font-geist-mono`，未新增字体文件或字体服务。
- AC-004：主模块卡片为白底、浅边框、10–12px 圆角，常驻状态无明显阴影。
- AC-005：侧边栏图标约 16px，图文间距约 8px，图标风格统一。
- AC-006：间距主要落在 4 / 8 / 12 / 16 / 24 / 32px 体系，不出现无依据拉伸。

### 17.2 首页结构

- AC-007：投放效率没有外层白色卡片，四张 KPI 卡直接位于浅灰背景。
- AC-008：来源全链路和每日趋势各自拥有完整白色主容器，标题、内容均在容器内。
- AC-009：首页没有重复大型漏斗、数据连接状态卡或未接入提示卡。
- AC-010：投放效率固定展示 ROAS、CPL、CPA、CPC 的本期、上期和周期变化，没有小折线。
- AC-011：全链路固定按来源为行，阶段为列；点击与官网访问只保留“访问（点击）”一列。
- AC-012：每个来源行末尾显示左侧共线、逐级变窄的 5 阶微型漏斗和整体转化率。
- AC-013：每日趋势左上只有来源和指标两个下拉，没有平铺指标按钮。
- AC-014：点击可选表头只改变趋势指标；趋势来源和投放效率不被隐式修改。
- AC-015：正常状态不显示更新时间、“最新”或“实时”。

### 17.3 状态、图表与可访问性

- AC-016：加载、真实零值、无数据、陈旧、错误和权限状态视觉与文案可区分。
- AC-017：所有百分比可通过 info 获取分母；未确认口径的转化率不展示。
- AC-018：图表当前周期为来源主色实线，上一周期为灰蓝虚线，并提供等价摘要或数据表。
- AC-019：颜色不是状态或涨跌的唯一表达方式。
- AC-020：所有交互可键盘触发并有可见焦点；Tooltip 可通过焦点访问。
- AC-021：`prefers-reduced-motion` 下无非必要动画，信息和最终布局不丢失。
- AC-022：320px 与 400% 缩放下无关键内容裁切，表格只在自身容器滚动。

### 17.4 视觉回归截图

- AC-023：至少保留 1440×1024 的市场总览正常态截图。
- AC-024：至少补充 390×844 的侧边栏覆盖态、首页纵向态和表格滚动态截图。
- AC-025：至少补充 Skeleton、空数据、部分来源错误、数据陈旧、权限阻断截图。
- AC-026：截图评审需核对侧栏宽度、卡片边界、模块间距、表格行高、图表比例和是否出现双重容器。

### 17.5 组件复用

- AC-027：Button、Select、Card、Table、Tooltip、Tag 等通用组件优先使用 Ant Design 或现有共享组件；同一语义在不同页面具有一致的尺寸、圆角、边框、悬浮、焦点、禁用和加载状态。
- AC-028：组件全局视觉差异通过 Theme Token 或共享 variant 实现，页面 CSS Module 不复制另一页面已有的通用组件外观；例外必须能指出明确业务原因。
