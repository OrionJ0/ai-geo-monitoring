# 冻结 v5 评测合同与回归夹具

## What to build

把 `three_track_partial_v1` 的输入、真值形状、实验臂、统计公式、硬门槛和注册表不变性指标固化为可重复执行的评测合同。评测必须复用完整历史回答，不重新向监测平台提问；旧合同的 41×3 结果作为不可变历史证据保留，新合同运行使用新的修订身份，不能覆盖或混算旧报告。

本切片交付一个可以在不调用真实模型时验证的完整评测骨架：语料去重和哈希、分层计数、缓存身份、配对统计、失败输出计数、门槛判定及中断恢复均可通过固定夹具证明。

## Acceptance criteria

- [ ] 冻结语料合同覆盖用户给出的六类问题，并能验证至少 40 条去重完整回答、目标出现/未出现、长回答、多实体和英文别名等分层要求。
- [ ] 答案哈希、prompt revision、模型、最终请求策略和实验修订共同决定缓存身份；任一关键项变化都不能误用旧输出。
- [ ] Wilson 区间、precision/recall/F1、exact-match、P95、重复一致率、集合 Jaccard 和配对差值均有确定性夹具。
- [ ] 评测报告把失败、部分结果和无法评估项计入正确分母，不因输出缺失而把它们当作成功。
- [ ] 人工真值不会进入任何模型提示或请求体；历史实验报告不会被新合同重写。
- [ ] 执行真实 API 前可先生成语料分层、缺失真值、预计调用量和门槛清单供审查。
