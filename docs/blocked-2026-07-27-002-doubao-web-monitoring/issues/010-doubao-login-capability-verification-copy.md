# 修正豆包登录验证与设置页刷新文案

## Parent

- PRD：`../prd.md`
- Tech Spec：`../TECH-SPEC.md`

## What to build

豆包匿名状态允许基础聊天，但“深入研究”需要登录。设置页的“验证登录”必须同时确认页面输入区与正式采集所需的“深入研究”能力，不能仅凭匿名输入区可用就显示登录有效。

保留用户可见按钮名“验证登录”。将只重新读取后端状态快照的“刷新状态”改为“重新加载”，并明确说明该操作只更新页面信息；真正检查网页登录有效性必须点击“验证登录”。

## Acceptance criteria

- [x] 豆包匿名页面存在输入区但点击“深入研究”弹出登录窗口时，“验证登录”返回需要登录。
- [x] 验证失败不会发送问题，也不会回退豆包 API。
- [x] “验证登录”按钮名称保持不变。
- [x] “刷新状态”改为“重新加载”，成功提示为“页面信息已更新”。
- [x] 页面明确说明“重新加载”只更新页面信息，“验证登录”才检查当前登录。
- [x] DeepSeek Web 既有登录验证行为保持兼容。
