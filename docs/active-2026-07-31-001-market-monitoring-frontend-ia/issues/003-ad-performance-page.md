## What to build

把现有合并营销页中的百度广告能力整理为可独立使用的“广告表现”页面。页面自动使用默认监控项目，展示同一完整本地快照，并提供“项目 → 推广计划 → 推广单元 → 投放关键词”的严格结构下钻。搜索词因上游没有关键词 ID，不嵌入这棵树。

页面保持只读，所有精确金额和计数继续使用现有精确值合同。任何账户失败都不能产生混合新旧快照；需要调整投放时只提供明确的百度营销外部入口。

## Acceptance criteria

- [x] 页面无需项目选择即可读取默认项目的广告快照。
- [x] 页面展示广告消费、展现、点击、覆盖范围和最后成功更新时间。
- [x] 多账户和同名推广计划能够通过账户标识区分。
- [x] 真实 Dashboard 的结构下钻覆盖推广计划、推广单元和投放关键词，并使用稳定父级 ID 组树。
- [x] 搜索词不按名称伪造关键词父级；后续使用独立分析视图。
- [x] 缓存新鲜时读取数据库；快照缺失或达到 10 分钟时由访问创建并等待共享的 `ON_DEMAND` 刷新，失败且有历史快照时保留最后成功数据。
- [x] 无快照、真实零数据、数据陈旧、刷新失败、归档和绑定异常具有不同状态。
- [x] 手动刷新保持项目级全成全败语义，运行中不会重复创建刷新。
- [x] 页面不提供预算、出价、推广计划或其他百度写操作。
- [x] 超出JavaScript安全整数范围的指标不会发生精度丢失。
- [x] 桌面端、移动端和等价数据表通过可访问性验证。
