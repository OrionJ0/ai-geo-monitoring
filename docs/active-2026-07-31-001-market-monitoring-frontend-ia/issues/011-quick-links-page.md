# 内部系统快捷导航页

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)

## What to build

在工作台侧边栏增加“快捷导航”直接入口，集中展示市场和管理工作中常用的外部系统。页面只负责提供清晰、可核对的入口，不代理登录、不保存来源系统凭据，也不在本系统执行来源业务操作。

入口按“投放与访问、接待与线索、官网与采购”分组，覆盖百度营销、上海广拓官网后台、基木鱼、百度巧舱、百度 Agent 对话页、营销通、爱番番、百度爱采购和百度统计。

## Acceptance criteria

- [x] 快捷导航位于设置正上方，是一级直接入口。
- [x] 页面完整展示九个指定系统及其用途说明。
- [x] 已知入口使用用户提供的官方地址并在新标签页打开。
- [x] 外部链接包含 `rel="noreferrer"` 和明确的可访问名称。
- [x] 百度爱采购同时提供买家平台和商家后台入口。
- [x] 基木鱼明确从百度营销后台进入，不把生成的落地页域名当作后台。
- [x] 百度 Agent 对话页在没有完整地址时只显示“完整地址待补充”，不生成虚构链接。
- [x] 分类标题独占完整内容行，网站卡片在下一行按网格展示，不使用左右分栏。
- [x] 每个网站使用对应 favicon 或官方品牌图，图标加载失败时保留文字回退。
- [x] 桌面端按三列卡片展示，窄屏切换为单列，沿用项目现有字体、色彩和间距。
