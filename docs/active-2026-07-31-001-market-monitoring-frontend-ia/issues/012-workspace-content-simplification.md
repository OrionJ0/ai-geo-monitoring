## What to build

按内部系统的最小充分原则清理工作台与管理员后台：侧边栏负责表达页面位置，主内容只保留数据、操作、状态、错误和必要口径。导航分组静态全展开；常用网站通过分组、图标和整卡点击表达用途。

## Acceptance criteria

- [x] 工作台和管理员侧边栏分组静态全展开，不存在 `openKeys`、`onOpenChange` 或 `SubMenu`。
- [x] 一级直接入口保持中性灰，不能点击的一级分组标题使用更浅灰色；二者字号和字重一致且不使用常驻底框。二级列表不使用底板、关系线或伪元素，仅使用统一缩进和较轻字号。
- [x] 正式工作台页面不重复侧边栏页名，不显示非必要眉题和介绍段。
- [x] 原始咨询和订单结果只显示最短来源状态，不显示数据范围说明卡片。
- [x] 市场总览删除跨来源归因、趋势阈值等常驻解释段，仍保留三个数据模块。
- [x] SEO 检测删除宣传性三卡片和装饰性 Hero 伪元素，网络范围说明改为简短状态加 Tooltip。
- [x] 管理员用户、会员、通知、健康和设置页面不重复侧边栏页名或常驻说明。
- [x] 常用网站不显示用途说明和独立“打开”链接，已知目的地整卡可点击。
