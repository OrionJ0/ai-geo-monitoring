# 新侧边栏与动态默认入口

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)
- 覆盖用户故事：US-003、US-005、US-006、US-008

## What to build

将工作台侧边栏重组为市场总览、投放与流量、转化结果、AI品牌监测、网站诊断、监测任务、快捷导航和设置等语义明确的入口，并让菜单名称、面包屑、选中态和默认入口来自同一导航合同。

完整信息架构立即向内部用户展示，市场总览成为工作台默认入口。来源能力只控制真实数据读取和刷新，不再隐藏菜单；未接入来源显示中性占位页。工作台设置分组不再提供管理设置跳转。

## Acceptance criteria

- [x] 侧边栏按照PRD确定的分组、名称和顺序展示。
- [x] 原“项目看板”“来源分析”“SEO检测”分别显示为“AI搜索表现”“引用来源分析”“SEO健康检测”。
- [x] 所有来源状态下均展示市场总览、投放与流量、转化结果及现有 GEO/SEO 入口。
- [x] 原始咨询和订单结果在无来源 API 时进入各自的只读占位页。
- [x] 工作台默认入口固定进入市场总览。
- [x] 菜单、面包屑和当前选中态对所有直接子路由保持一致。
- [x] 原“系统”分组改名为“设置”，仅保留系统通知和个人中心，不提供管理设置跳转。
- [x] 六个一级分组使用下拉展开，当前页面所属分组自动展开，并允许多个分组同时保持展开。
- [x] 窄屏使用覆盖式侧栏，点击菜单后自动收起；键盘操作、焦点状态和可访问名称通过验证。
- [x] 管理员后台增加返回数据工作台、后台总览和历史记录直接入口；账号与权限、系统管理复用同一下拉与移动端侧栏交互。
- [x] Header 与 Sider 固定，HTML/body 不滚动，仅主内容区滚动；一级菜单基础字体样式统一。
- [x] 一级菜单基础颜色从近黑调整为中性灰，直接入口与分组标题保持一致。
- [x] 快捷导航作为设置上方的同级直接入口，菜单、面包屑和选中态共用导航合同。
