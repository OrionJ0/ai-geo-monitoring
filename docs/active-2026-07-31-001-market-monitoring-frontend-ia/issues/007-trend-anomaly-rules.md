# 趋势异常规则校准与接入

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)
- 覆盖用户故事：US-002

## What to build

基于广拓真实历史数据评审并确定趋势异常的历史基线、最小样本量、指标阈值、连续天数和规则版本。产品确认后，将连续趋势和单日显著波动接入“需要关注”，继续沿用既有排序、合并和下钻合同。

规则必须使用精确整数比较，能够解释触发依据，且不得因为广告与网站指标同期变化而生成因果结论。

## Acceptance criteria

- [ ] 产品负责人确认每项趋势规则的指标、基线、最小样本、阈值、连续天数和启用版本。
- [ ] 未达到最小样本量时不生成趋势异常。
- [ ] 趋势比较不通过浮点聚合造成大整数精度损失。
- [ ] 连续趋势优先于单日波动，核心结果指标优先于低影响指标。
- [ ] 同类异常只有在来源、时间窗口、方向和下钻入口一致时才能合并。
- [ ] 跨来源同期下降可以并列描述，但不得使用“导致”“带来”等归因措辞。
- [ ] 规则版本关闭或缺失时系统安全退回仅显示数据健康事项。
- [ ] 使用脱敏历史样本完成误报、漏报和边界值人工评审。
