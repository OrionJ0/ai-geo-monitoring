# 数据健康类需要关注事项

## Parent

- [PRD](../prd.md)
- [Tech Spec](../TECH-SPEC.md)
- 覆盖用户故事：US-002

## What to build

在市场总览中生成可解释、可复现的数据健康事项，覆盖授权失效、连接异常、绑定阻断、刷新失败和数据陈旧。候选事项按照确定性优先级排序，首页最多展示三条，每条都能下钻到证据或恢复入口。

本切片不实现尚未批准阈值的趋势波动判断，也不使用AI生成建议。

## Acceptance criteria

- [ ] 数据健康事项由稳定状态和错误码推导，不依赖自然语言错误内容。
- [ ] 授权失效、连接异常、绑定阻断、刷新失败和数据陈旧能够分别识别。
- [ ] 超过三条候选时使用稳定优先级和稳定ID选择前三条。
- [ ] 同一来源和同一恢复入口的重复事项可以合并，并保留全部证据。
- [ ] 不同来源、不同原因或不同恢复入口的事项不会强行合并。
- [ ] 每条事项展示对象、原因、时间信息和可用下钻入口。
- [ ] 没有批准的趋势规则时不会产生点击、消费或访客波动事项。
- [ ] 固定输入重复执行得到完全一致的输出和顺序。
