# 交付全部渠道趋势与全链路表格联动

## Parent

- `../prd.md`
- `../TECH-SPEC.md`

## What to build

在保留现有全链路表格结构的前提下，把每日趋势默认改为全部渠道同图比较，提供可访问图例、渠道占比和周期变化；可对齐百度统计的表格渠道行能够切换单渠道趋势，原有下钻链接和官网表单专属来源行保持各自语义。

## Acceptance criteria

- [x] 来源默认显示“全部”，页面不再出现“官网全站（百度统计）”。
- [x] 全部模式同图展示全部访问及七个可用渠道，只提供访问指标。
- [x] 自定义图例支持鼠标和键盘隐藏/恢复渠道，并展示占比和周期变化。
- [x] Tooltip 先展示全部访问，再按当日访问量排序渠道，精确值不经过浮点推算。
- [x] 百度推广单渠道支持投入、展现和访问，其他渠道只支持访问。
- [x] 可对齐渠道行支持点击、Enter 和 Space 联动；下钻链接不触发行联动。
- [x] UTM、UNKNOWN 等官网表单专属行不提供虚假访问趋势。
- [x] “官网表单咨询”改为“官网咨询”，同时明确不包含 53KF。
- [x] 桌面、移动、reduced-motion、axe 和页面横向溢出验收通过。
