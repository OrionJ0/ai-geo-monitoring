# 增强结构化分析纠错与精确证据归一化

## Parent

- `../TECH-SPEC.md` U4
- 覆盖 AC-009、AC-010、AC-011

## What to build

让结构化分析第二次尝试针对具体字段错误重新审阅完整回答，并在同一实体仍有至少一个精确可定位表面词时，丢弃无原文依据的附加名称并留下有界诊断。没有任何精确证据的实体和其他非法结构仍整条失败，不能进入品牌指标。

## Acceptance criteria

- [x] 二次重试提示包含结构化字段路径、错误类型和可执行纠正要求，并重新输出完整 v4 对象。
- [x] 同一实体有精确表面词时，无效附加表面词被丢弃且不参与任何指标，并记录有界 warning。
- [x] 实体全部表面词无效，或关系、候选、情绪引用不存在实体时，继续返回 `invalid_analysis_output` 且不写指标。
- [x] 分析契约和指标语义版本保持不变，提示词修订显式升级。
- [x] analysis-only 重试复用原回答与引用，不调用监测平台、不消耗监测配额，并保留重试链路。

## Blocked by

None - can start immediately
