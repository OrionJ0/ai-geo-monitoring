# 让运行状态可观察并保证暂停恢复幂等

## Parent

- `../TECH-SPEC.md` U1
- 覆盖 AC-001、AC-002、AC-003、AC-004

## What to build

让问题集报告从真实执行租约派生正在执行、等待处理、暂停收尾、已暂停和终态，并让暂停、继续命令在重复或并发请求下只发生一次有效状态迁移和一次恢复调度。前端在控制请求完成前阻止重复提交，并向用户准确说明 soft pause 不会中断已经发出的平台请求。

## Acceptance criteria

- [x] 报告保留既有状态字段，并新增控制状态、执行中数量、排队数量和行级执行状态；执行中与排队数量之和始终等于待处理数量。
- [x] 暂停后不再领取新任务；已领取任务完成前显示“暂停收尾中”，全部收尾后仍有排队项时显示“已暂停”。
- [x] 两个并发继续请求只有一个取得恢复权并触发一次调度，重复暂停或继续返回可解释的幂等结果。
- [x] 暂停或继续请求提交期间按钮处于 loading/disabled，不会再次发出同类请求。
- [x] API 不暴露执行 token、租约 owner 或租约到期时间，存量报告缺少新增字段时仍可展示。
