# ADR 0002：固定营销数据 AI 报告使用应用构建的证据包

首版固定营销数据 AI 报告不使用 Agent、模型工具调用或多步自主查询。应用在模型调用前，通过既有来源模块提供的窄只读内部端口重新读取百度推广、百度统计和官网表单数据，由程序完成精确指标、比较资格、排序、覆盖状态与样本边界计算，锁定一个版本化、有界 JSON 证据包；模型只接收该证据包并一次生成结构化报告，核心结构无效时最多纠正一次。

来源读取、质量核对和权限判断都是应用职责，不是暴露给模型的工具。任何来源失败、覆盖不完整或语义不一致，都必须在证据包中诚实标记为失败、缺失或不可比较，模型不得再调用 HTTP、数据库或其他接口“核对”，也不得用旧缓存或同期来源补齐。

该决定使固定报告的成本、延迟、输入和故障路径可预测，并确保历史报告绑定生成当时的数据与结论。未来若新增交互式“问数据”，应作为独立需求重新评审受限、无会话的只读工具循环，不得把它静默引入首版固定报告。
