# ADR 0002：营销数据 AI 分析使用受控只读工具

营销数据 AI 分析只允许模型选择后端注册的受控只读工具，由应用绑定当前用户、监控项目和固定分析数据基线，并在既有营销数据模块内部复用查询能力；模型不得提交 URL、凭据、用户标识或项目标识，也不得通过后端自调用现有 HTTP API。该边界保留营销、官网表单等来源模块各自的权限、缓存和错误语义，避免自调用 HTTP 带来的身份代传、重复鉴权与运行内数据漂移；未来如需 MCP，只能适配同一工具合同，不得扩大数据或写操作权限。
