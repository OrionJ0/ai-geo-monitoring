# ADR 0004：营销 AI 报告只接收最小化搜索词样本

完整搜索词事实只在百度营销来源模块内参与程序计算，不整体发送给模型，也不在营销 AI 报告模块中另建原始数据副本。进入固定证据包的搜索词只能是按稳定排序和确定性配额选出的有限样本；样本必须先清理控制字符、限制单条与总长度、遮蔽明显手机号、邮箱和身份证号，并移除内部 ID、账户 ID、项目 ID 及其他记录标识。

报告必须携带样本数量、总量或可知覆盖范围及“仅代表有限样本”的限制说明。搜索词文本即使包含提示注入内容也只作为不可信数据处理，不能改变系统指令、请求联网、触发工具或扩大数据范围。

该决定优先满足数据最小化、成本可控和可复现性。若有限样本不足以支持某项结论，报告应明确降低结论范围，而不是扩大模型输入或让模型自行查询完整搜索词。
